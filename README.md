# zh-lyric-adaptation

给日文歌填中文词。按拍定字，按耳朵断句，按语域定调。

填词不是翻译。一句日文七个音，中文就得七个字，多一个字唱不进去，少一个字会漏气。这套东西管的就是这件事：把拍拆开，字填进去，最后拿脚本验一遍。

## 两件工具

`scripts/pair_table.py` 把罗马音和中文并排成一张对照表，一拍一字，上下一一对应：

```
$ python3 scripts/pair_table.py 词.tsv
第1句（6+4）
  no-bo-ru-tsu-ki-wo｜se-o-i-te
  身-负-初-升-之-月｜霜-落-双-肩
```

`scripts/check_lyric.py` 逐句核字数、断点、韵脚。字数对不上拍数、断点落在词中间、韵脚重字，都会报出来，退出码非零：

```
$ python3 scripts/check_lyric.py 词.tsv
```

输入是同一个 TSV，每行一句，两列，TAB 分隔：罗马音在前，中文在后，拍用 `-` 分，断点用 `|`。

## 几条硬规矩

**LRC 的行界不是乐句的界。** 实测一首 33 句的曲子，有两处整整错开一句，一句的尾巴归到了下一句开头。照 LRC 填，必然一歌词卡前面、一歌词卡后面。

**不要用脚本找拍点。** 谱通量起音检出 843 个，全曲实际 381 拍，过检 2.2 倍；自相关给出 2:1 的双峰，定不了拍。脚本只验字数、断点、韵脚、声调，不分析节奏。

**断点要落在词的边界上。** 双音节词不许被 `|` 劈开，否则换气就断词。断点由唱的人划，不由机器猜。

**一字一拍的规矩别轻易破。** 靠「末音吃掉一拍」自动减字的算法会被耳朵推翻：减掉的那一拍不会消失，只会在句中挖出一个洞。确要减，先问，且只减句末。

**出戏是字的问题，不是节奏的问题。** 全曲古语，混进「好好地」「指尖」「那头」「谎话」，那个人忽然就不认识这个声音了。这时候不改拍数，只改语域。

其余细则在 SKILL.md：拗音算一拍、ー/ん/っ 各占一拍、手打的罗马音会漏连字符、减字处的末字要能拖、句末声调跟旋律走。

## 安装

作为 Hermes skill：

```bash
cp -r . ~/.hermes/skills/creative/zh-lyric-adaptation
```

脚本只要 Python 3 和 `pypinyin`：

```bash
pip install pypinyin
```

## 词韵粗分

`check_lyric.py` 按十三辙粗分韵部：言前、中东、油求、江阳、发花、梭波、灰堆、姑苏、衣期、遥条、怀来。日常填词够用。要更细的韵，改脚本里的 `GROUPS` 表。
